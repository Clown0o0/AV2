##  Guia de Inicialização

Siga os procedimentos abaixo para configurar o ambiente de desenvolvimento local.

### Pré-requisitos

Para garantir a estabilidade do sistema, certifique-se de possuir:
- **Node.js:** Versão 18.x ou superior (LTS recomendada).
- **Gerenciador de Pacotes:** npm (v9+) ou yarn.
- **Git:** Para controle de versão.

### Instalação e Execução

1. **Clonagem do Repositório**
   Realize o clone do código fonte para sua máquina local:
   ```bash
   git clone https://github.com/Clown0o0/AV2

   Acesse a pasta raiz do projeto frontend:

   cd frontend-app

   Instale os pacotes necessários definidos no ecossistema do projeto:

   npm install

   Inicie o servidor de desenvolvimento com suporte a hot-reload:

   npm run dev
   

  O sistema estará disponível através do endpoint local:
  
  
  👉 http://localhost:3000
